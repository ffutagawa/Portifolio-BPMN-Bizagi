# Portfólio de Bizagi e BPMN | Fabrício Futagawa

Estudos demonstrativos de gestão de serviços de TI, inspirados na minha experiência com sustentação de ERP. O portfólio mostra como estruturar responsabilidades, registrar decisões e definir indicadores em processos de TI.

| Estudo de caso | O que demonstro | Diagrama e modelo |
| --- | --- | --- |
| Gestão de incidentes de ERP | Triagem por impacto e urgência, escalonamento e validação da restauração com o negócio. | [Diagrama](assets/diagramas/01-gestao-incidentes.svg) · [BPMN](assets/modelos/01-gestao-incidentes.bpmn) |
| Gestão de mudanças de TI (GMUD) | Avaliação de risco, autorização, testes e plano de reversão. | [Diagrama](assets/diagramas/02-gestao-mudancas.svg) · [BPMN](assets/modelos/02-gestao-mudancas.bpmn) |
| Análise de problemas recorrentes | Investigação de causa raiz, reavaliação de pendências e verificação de eficácia. | [Diagrama](assets/diagramas/03-gestao-problemas.svg) · [BPMN](assets/modelos/03-gestao-problemas.bpmn) |

Os cenários AS-IS são hipotéticos. Os diagramas TO-BE representam propostas, e os indicadores foram definidos para uma futura avaliação em piloto. Os arquivos BPMN 2.0 estão disponíveis para revisão no Bizagi Modeler.

## Visualização interativa

O site está pronto para servir a partir da raiz do repositório. Se estiver hospedado no GitHub Pages, o endereço aparece em **Settings → Pages**. Para visualizar localmente, execute na pasta extraída:

```sh
python -m http.server 8000
```

Depois acesse [localhost:8000](http://localhost:8000).
